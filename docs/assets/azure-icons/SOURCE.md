# Azure architecture icons

The three SVG files in this directory were extracted from Microsoft's official **Azure Public Service Icons V24** package.
The [Azure Architecture Center icon page](https://learn.microsoft.com/en-us/azure/architecture/icons/) links to the package.
The icons are used only to identify Azure products in the report architecture diagram.
The icons are embedded in `../integrated-system-architecture.drawio` without changes.
