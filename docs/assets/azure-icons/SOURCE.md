# Azure architecture icons

The three SVG files in this directory were extracted from Microsoft's official **Azure Public Service Icons V24** package, linked from the [Azure Architecture Center icon page](https://learn.microsoft.com/en-us/azure/architecture/icons/). They are used only to identify Azure products in the report architecture diagram. The icons are embedded in `../integrated-system-architecture.drawio` and are not modified.
